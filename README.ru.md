ClipTime Local — это автоматизированная локальная утилита, которая превращает длинные широкоформатные видео в вовлекающие вертикальные клипы (9:16), идеально подходящие для TikTok, YouTube Shorts и Instagram Reels.

Программа обрезает оригинальное видео, заполняет пустое пространство красивым размытым фоном (blur) и автоматически генерирует динамические субтитры прямо поверх видео с помощью нейросетей.

## ✨ Основные возможности

- 📱 **Вертикальный формат:** Конвертация широких видео в мобильный формат 9:16.
- 🌫️ **Размытый фон:** Автоматическое заполнение пустых областей сверху и снизу размытым фоном из самого видео.
- 💬 **Динамические субтитры:** Точное распознавание речи (Whisper AI) и наложение красивого текста.
- ⚡ **Локальная работа:** Вся обработка происходит на вашем компьютере. Не нужно загружать гигабайты видео в облачные сервисы.
- 🎛️ **Настройка нейросети:** Выбор между быстрыми и точными моделями распознавания.

## 🚀 Первый запуск

1. Нажмите правой кнопкой мыши на файл `setup.ps1` и выберите **«Выполнить с помощью PowerShell»**.
2. Дождитесь окончания установки зависимостей и запустите `start.ps1` тем же способом.
3. Веб-интерфейс программы откроется по адресу `http://localhost:3000`.

*Если система безопасности PowerShell блокирует запуск скриптов, откройте консоль PowerShell в папке проекта и выполните:*
```powershell
powershell -ExecutionPolicy Bypass -File .\setup.ps1
powershell -ExecutionPolicy Bypass -File .\start.ps1
```

## ⚙️ Настройки и результаты

Готовые срендеренные видео сохраняются в папке `local_data/outputs/<номер-задачи>`.

По умолчанию для распознавания текста используется модель `small`, работающая на мощностях процессора (CPU).
- Для **более быстрой** работы (с потерей точности) задайте переменную: `CLIPCRAFT_MODEL=base`
- Для **максимальной точности** (работает медленнее) задайте: `CLIPCRAFT_MODEL=medium`

> **Внимание:** Скачивайте и обрабатывайте только те видео, на использование которых у вас есть законное разрешение или авторские права.
