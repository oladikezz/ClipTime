# ClipTime Local

Локальная программа для превращения длинных видео в вертикальные клипы 9:16 с размытым фоном и динамическими субтитрами.

## Первый запуск

1. Нажмите правой кнопкой на `setup.ps1` и выберите «Выполнить с помощью PowerShell».
2. После установки запустите `start.ps1`.
3. Интерфейс откроется по адресу <http://localhost:3000>.

Если PowerShell блокирует запуск, откройте PowerShell в папке проекта и выполните:

```powershell
powershell -ExecutionPolicy Bypass -File .\setup.ps1
powershell -ExecutionPolicy Bypass -File .\start.ps1
```

Готовые видео сохраняются в `local_data/outputs/<номер-задачи>`.

По умолчанию распознавание использует модель `small` на процессоре. Для более быстрого режима задайте `CLIPCRAFT_MODEL=base`, для более точного — `medium`.

Скачивайте и обрабатывайте только видео, на использование которых у вас есть разрешение.
